# Who Called? sample backup

Import `who-called-sample.contactvault` from **Settings → Restore encrypted backup**.

Password: `12345678`

Restoring replaces the current contacts, saved messages, tagged numbers, and settings. The sample
contains four contacts covering full and month/day birthdays, three named anniversaries, active and
inactive reminders, multiple phone numbers, a hidden contact, favourites, email addresses, and
social links.

To regenerate the encrypted file:

```bash
npm run generate-sample-backup
```
